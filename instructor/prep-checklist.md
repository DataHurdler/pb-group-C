# Prep Checklist

## Two weeks before

- [ ] Open questions Q3, Q4, Q14, and Q15 answered ([course-plan/open-questions.md](../course-plan/open-questions.md))
- [ ] Every lab run end to end, timed, by someone other than its author, on
      **at least two different AI tools' free tiers**
- [ ] Pre-check piloted on 2–3 people from the target audience
- [ ] Room booked for 8:15–16:30; layout supports pairs (tables, not rows)
- [ ] Lunch arranged (or nearby options listed if not provided)
- [ ] Pre-arrival message sent (below)

### Pre-arrival message

> **AI Prompting for Innovators: [date], 9:00–16:00, [venue]**
>
> Please bring:
> - A laptop and charger
> - A **free account on at least one AI chat assistant** (ChatGPT, Claude,
>   Gemini, or Copilot). Sign up and log in **before** the day; venue Wi-Fi
>   isn't the place to verify an email address
> - **One idea, venture, or work problem** you'd like to make progress on. It
>   can be small. Please don't bring anything confidential; you'll describe it
>   in general terms
>
> No technical background needed. Lunch is [provided / nearby].

## Three days before

- [ ] Slides final; exported to PDF as a backup
- [ ] Printed (headcount + 10%): practice case, Labs 01–04, reference sheet,
      capstone brief (one per table)
- [ ] Pre-check, post-check, exit ticket printed or forms live
- [ ] **Shared prompt document** created; link on the welcome slide
- [ ] Reminder sent, repeating the account sign-up request
- [ ] Re-run the Module 01 hook prompt in two tools. Model behaviour changes
      over time; make sure it still gives a generic answer worth showing

## Day of — bring

- [ ] Laptop, charger, adapter for the room's display
- [ ] Slides on the laptop **and** a USB stick or cloud link
- [ ] Logins for two AI tools on your own machine
- [ ] Printed handouts, index cards, markers
- [ ] A timer visible to the room
- [ ] This repo, open, with [run-of-show.md](run-of-show.md) on screen

## Contingency plans

| If… | Then… |
| --- | --- |
| Wi-Fi fails | Phones on mobile data in pairs (one working device per pair is enough). If that fails too: run labs as instructor demos from a hotspot, with the room calling the prompts |
| A major AI tool is down | Pairs move to whichever tool works. Every lab is tool-agnostic |
| Participants hit free-tier caps | Switch tools, or continue in a new chat by pasting their brief. Lab 03 notes this |
| Projector fails | Printed reference sheet at each table; teach from it |
| Half the room is late | Start on time with Module 00 anyway |
| Far more people than expected | Groups of 3 instead of pairs in the morning; random share-outs only |
| A lab clearly isn't working mid-session | Stop it, demonstrate it yourself, move on. Note it for the exit-ticket review |

## After the day

- [ ] Read exit tickets the same evening
- [ ] Compare pre/post results per item
- [ ] Record what to change before the next offering
- [ ] Send participants the shared-document link and the reference sheet
