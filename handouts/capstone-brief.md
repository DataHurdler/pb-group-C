# Capstone Brief — Build Your Prompt Kit

**14:30–15:25 · 55 minutes · individually, then swap with your partner**

## The task

Turn one prompt into a **template you'll reuse**: tested, improved, and clear
enough that someone else can use it.

## The finish line

By 15:25 you have:

- [ ] A template with `[CAPITAL SLOTS]` for the parts that change
- [ ] A header: **Use this for** / **Don't use this for** / **Check before
      using the output**
- [ ] A log of at least **two rounds** of *what I changed → what happened*
- [ ] Your partner has run it on their own idea and it passed your criteria (or
      you fixed what didn't)
- [ ] Posted to the shared document

## The clock

| By | Have done |
| --- | --- |
| 14:35 | Picked a task you'll do more than once |
| 14:40 | Written 3–4 yes/no criteria, **before** running anything |
| 14:50 | Run it once and scored it |
| 15:05 | At least two one-change rounds, logged |
| 15:15 | Templatized, with header |
| 15:25 | Partner-tested and fixed |

## Rules

1. **Criteria before output.** No changing them after you've seen the result.
2. **One change per round.** If you change two things, you won't know which
   one helped.
3. **Nothing confidential.** Use general descriptions.

## Share-out at 15:30 (60 seconds per pair)

Show **one** template. Say: the one change that helped most, and what you
wrote under "Don't use this for".
