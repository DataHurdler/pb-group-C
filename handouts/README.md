# Handouts

Things participants keep or use during the day. Each one fits on one page.

| Handout | What it is | Given at |
| --- | --- | --- |
| [reference.md](reference.md) | The one-page reference: how it works, the prompt brief, five moves, refinement, template format, red lines. **The take-home** | Module 02 (10:35); used for the rest of the day |

| [capstone-brief.md](capstone-brief.md) | The Lab 04 task, finish line, and clock | 14:05 break, on every table |

The [practice case](../labs/practice-case.md) lives with the labs, since it's
only used in the morning.

## Rules

- One page each. If it doesn't fit, it's two handouts or too much content.
- Written for someone who wasn't in the room, since that's who reads it in a
  month. That includes the participant, who will have forgotten the context.
