# Handouts

Things participants keep or use during the day. Each one fits on one page.

| Handout | What it is | Given at |
| --- | --- | --- |
| [reference.md](reference.md) | The one-page reference: how it works, where it fits, the prompt brief, ground → ask → check, refinement, template format, red lines. **The take-home** | Module 02 (10:35); used for the rest of the day |
| [prompt-log.md](prompt-log.md) | A log for prompts, iteration rounds, and checks | Module 01 (shared link) |
| [capstone-brief.md](capstone-brief.md) | The Lab 04 task, finish line, and clock | 14:05 break, on every table |
| [use-case-canvas.md](use-case-canvas.md) | One-page AI use-case plan: task, where AI fits, value, data and policy, risks, pilot. **The second take-home** | 14:05 break, one per person |

The [practice case](../labs/practice-case.md) and
[practice data](../labs/practice-data.md) live with the labs.

## Rules

- One page each. If it doesn't fit, it's two handouts or too much content.
- Written for someone who wasn't in the room, since that's who reads it in a
  month. That includes the participant, who will have forgotten the context.
